# IX Coffee
Autumn coffee shop website with a light Halloween touch (WEB Technologies 1, Midterm + Endterm).
Pages: `index.html`, `menu.html`. Stack: HTML5, CSS (Bootstrap 5.3), JavaScript, jQuery 3.7.

- `css/style.css` - all styles
- `js/script.js` - falling leaves
- `js/menu.js` - menu data array, cards, search / filter / sort
- `js/cart.js` - cart and totals
- `js/form.js` - pre-order form validation
- `js/effects.js` - jQuery effects (smooth scroll, accordion, fades, slide message)
- `images/` - menu photos
